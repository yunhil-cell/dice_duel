현재 규칙

  • 각 플레이어는 3개 라인을 가지며, 각 라인은 3칸입니다.
  • 선공은 참가자 입장 시 랜덤으로 결정됩니다.
  • 내 차례가 오면 직접 주사위 굴리기 버튼을 눌러 진행합니다.
  • 일반 주사위는 내 라인에 배치하거나 같은 숫자의 상대 주사위를 제거하는 데 사용할 수 있습니다.
  • 제거 성공 시 보너스 주사위를 한 번 더 굴리고, 그 주사위는 내 라인 또는 상대 라인에 배치할 수 있습니다.
  • 보너스 주사위는 제거에 사용할 수 없고, 배치되면 방어 상태가 됩니다.
  • 같은 줄에 같은 숫자가 여러 개 있으면 보너스 점수를 받습니다.
  • 양쪽 모두 더 이상 자기 필드에 배치할 수 없으면 게임이 종료됩니다.
